# Security policy

## Supported versions

The latest tagged release is supported. Fixes are applied to the `main` branch
and released when a fix is ready.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private
security-advisory reporting for this repository, or contact the maintainer
through the profile linked from the repository page.

Do not include real credentials, private theme data, or sensitive filesystem
contents in a report.
